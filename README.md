Introduction to DAX in Power BI, 10/05/2026, [a link to your published Tableau workbook](https://public.tableau.com/app/profile/harmony.sample/viz/PowerBITrainingCertifications_17908270910850/PowerBIStory?publish=yes), In Flex 3, I built a calculated field in Tableau called Profit Margin (%) using the Num Order Info table (equation: SUM([Profit])/SUM([Revenue])) in order to compare subcategory performance in my applied chart. In Power BI, I would build this as a measure (Profit Margin (%) = DIVIDE(SUM('Num Order Info'[Profit]), SUM('Num Order Info'[Revenue])) because margin is a ratio of totals, and averaging row-by-row percentages across a subcategory or region gives the wrong answer. With a measure, Anita will be able to filter margin by category, region, or month with ease and accuracy. This is critical as it allows Anita to answer her own follow-up questions without having to go through the trouble of contacting me or waiting for an answer/new report.

Data Visualization in Power BI, 10/11/2026, [a link to your published Tableau workbook](https://public.tableau.com/app/profile/harmony.sample/viz/PowerBITrainingCertifications_17908270910850/PowerBIStory?publish=yes), In Flex 3, I created a Profit Margin (%) calculated field in Tableau, SUM([Profit])/SUM([Revenue]), and charted it by subcategory. In Power BI, I would rebuild that view as a table with conditional formatting on the margin column. That way, any subcategories losing money show up in red right in the table Anita already reads, so she doesn’t need a separate chart. I would calculate margin with a DAX measure, DIVIDE(SUM(‘Num Order Info’[Profit]), SUM(‘Num Order Info’[Revenue])), so it’s always total profit divided by total revenue. That keeps the number accurate as Anita filters by category, region, or month.
